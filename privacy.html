Privacy Policy for COQL Editor

Effective Date: September 11, 2026

COQL Editor is a Zoho CRM extension developed and maintained by Sakura Extensions.

This Privacy Policy explains how COQL Editor accesses, processes, and handles information when you use the extension.

1. Purpose of COQL Editor

COQL Editor is a developer and administration tool designed to help Zoho CRM users create, format, execute, and analyze COQL queries directly inside Zoho CRM.

The extension may provide functionality such as query execution, IntelliSense, module and field metadata suggestions, picklist value suggestions, related-module navigation, date helpers, pagination, CSV export, syntax highlighting, and query formatting.

2. Information Accessed by COQL Editor

COQL Editor may access information from your Zoho CRM organization when necessary to provide its functionality.

This may include:

  • CRM module metadata
  • CRM field metadata
  • Picklist values
  • Related module information
  • CRM records returned by COQL queries initiated by the user
  • Basic Zoho CRM session information required to operate the extension

COQL Editor accesses this information only through Zoho's official platform, APIs, and SDKs and according to the permissions granted by the Zoho CRM organization and user.

3. Data Collection by Sakura Extensions

Sakura Extensions does not operate an external database or server that collects or stores Zoho CRM records processed through COQL Editor.

COQL Editor does not send CRM query results, CRM records, passwords, OAuth access tokens, refresh tokens, client secrets, or CRM credentials to servers operated by Sakura Extensions.

4. Local Browser Storage

COQL Editor may use browser local storage to save application preferences and improve the user experience.

This may include:

  • Theme preferences
  • Editor preferences
  • Recent queries or query history
  • Other non-server-side application settings

This information remains within the user's browser or device and is not transmitted to Sakura Extensions.

Because users control the queries they write, query history may contain field names, identifiers, search criteria, or other information entered by the user. Users should avoid placing sensitive information directly inside queries unless required for their legitimate CRM activities.

5. Query Results

COQL query results are processed and displayed inside the user's Zoho CRM environment and web browser.

Sakura Extensions does not retain copies of those results on external Sakura Extensions servers.

If a user chooses to export results to CSV, the file is generated for the user through the browser and downloaded to the user's device.

6. Authentication and Credentials

COQL Editor does not require users to manually provide Zoho CRM passwords, OAuth access tokens, refresh tokens, or client secrets.

Authentication and authorization are handled through the Zoho platform and the permissions associated with the installed extension.

7. Third-Party Services

COQL Editor relies on Zoho CRM and Zoho platform services to provide its core functionality.

Data processed through Zoho services is subject to Zoho's own privacy, security, and data-processing practices.

COQL Editor does not currently use third-party advertising networks or third-party analytics services to collect CRM data.

8. Data Retention

Sakura Extensions does not retain Zoho CRM query results or CRM records on external Sakura Extensions infrastructure.

Information stored locally in the browser remains there until it is removed by the user, cleared by the browser, or removed by COQL Editor.

9. Data Security

COQL Editor is designed to minimize unnecessary data transmission and to use Zoho's official APIs and SDKs for communication with Zoho CRM.

Users and organizations remain responsible for managing Zoho CRM permissions, user access, data governance, and appropriate use of CRM information.

10. User Responsibility

Users are responsible for the COQL queries they execute and for ensuring that their use of CRM data complies with their organization's policies, applicable laws, and Zoho's terms and conditions.

11. Children's Privacy

COQL Editor is intended for business, administrative, and developer use within Zoho CRM and is not designed or marketed for use by children.

12. Changes to This Privacy Policy

Sakura Extensions may update this Privacy Policy when COQL Editor changes, new functionality is introduced, or privacy practices are updated.

The latest version of this Privacy Policy will be published at this URL with an updated effective date.
