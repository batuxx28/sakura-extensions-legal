Overview

COQL Editor is a developer-friendly query workspace built directly inside Zoho CRM.

It helps administrators, developers, consultants and power users create and execute COQL queries faster using intelligent suggestions based on the modules and fields available in their own CRM.

Smart IntelliSense Modules, fields, related fields and COQL keywords.
Picklist suggestions Use real Zoho CRM picklist values while writing filters.
Date support Insert Date and DateTime values using Zoho-compatible formats.
Live results Preview query results in table or JSON format.
CSV export Export query results directly from the extension.
Related fields Navigate lookup relationships using dot notation.

Getting Started

1. Open COQL Editor

After installing the extension, open the COQL Editor web tab inside Zoho CRM.

2. Write a query

SELECT id, Deal_Name, Stage
FROM Deals
WHERE Stage = 'Closed Won'
LIMIT 200

3. Run the query

Click Run or use Ctrl/Cmd + Enter.

4. View the results

Results can be displayed as a table or JSON.

Features

IntelliSense

Press Ctrl/Cmd + Space to open suggestions manually. Suggestions also appear automatically while typing. 

SELECT Deal_Name, Account_Name.

When a field is a lookup, COQL Editor can load fields from the related module and suggest values such as: 

Account_Name.Account_Name
Account_Name.Owner
Account_Name.Industry

Picklist values

WHERE Stage = 'Closed Won'

For picklist fields, COQL Editor shows the actual values configured in your Zoho CRM organization.

Picklist suggestions also work with: 

WHERE Stage IN ('Closed Won', 'Qualification')

Date and DateTime

Date fields use the Zoho-compatible format: 

'2026-09-11'

DateTime fields use an ISO-style format with timezone: 

'2026-09-11T10:30:00-05:00'

Formatting

Use the Format button to improve readability of your COQL query.

Copy as one line

The Copy 1 line button converts the query into a single-line format for use in scripts, API tools or functions.

Examples

Basic query

SELECT id, Full_Name
FROM Contacts
LIMIT 200

Filter by picklist

SELECT Deal_Name, Stage
FROM Deals
WHERE Stage IN ('Closed Won', 'Qualification')
LIMIT 200

Related module field

SELECT Deal_Name, Account_Name.Account_Name
FROM Deals
LIMIT 200

Date filter

SELECT id, Deal_Name, Closing_Date
FROM Deals
WHERE Closing_Date >= '2026-01-01'
LIMIT 200

Pagination and Limits

COQL Editor allows up to 2,000 records per API request.

The page selector can be used to navigate through additional records.

The Load All option is intentionally limited to 20,000 records to maintain a responsive user experience. COQL Editor loads the data in batches in the background.

For larger exports, users should use Zoho CRM Bulk Read or apply more specific filters.

FAQ

Does COQL Editor store my CRM data?

COQL Editor is designed to execute queries inside the Zoho CRM environment. Query results are displayed in the browser and are not intended to be stored on an external application server by the extension.

Do I need to provide an OAuth token?

No. The extension uses the Zoho CRM widget environment and the permissions granted during installation.

Does IntelliSense consume an API call every time I type?

No. Metadata is loaded only when necessary and reused during the current session whenever possible.

Why is Load All limited to 20,000 records?

The limit is intended to keep browser memory usage, rendering time and overall performance predictable.

Can I export results?

Yes. Results can be exported as a UTF-8 CSV file.
